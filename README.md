# 👾 Selva Template Three - Luminous Purple Edition

Welcome to the **Luminous Purple Edition** of Team Selvador's official gaming platform! This is a distinct, high-performance web template built completely from scratch, featuring a futuristic cyberpunk neon aesthetic. 

This version drops the traditional color schemes for a dark-mode environment powered by deep violets, glowing purples, and electric fuchsia accents.

🌐 **[Live Demo](https://ahmedadel-selva.github.io/Selva-Template-Three-Luminous/)** *(ملحوظة: استبدل هذا الرابط برابط الـ GitHub Pages الفعلي بعد الرفع)*

---

## ✨ Features & Visual Theme

*   **Luminous Aesthetics:** A customized dark theme (`#000000eb`) integrated with vivid neon highlights (`#762abe` and `#f309f4`) for a premium gaming vibe.
*   **100% Responsive Design:** Meticulously optimized using CSS Flexbox and Grid to ensure a flawless experience across modern smartphones, tablets, and desktops.
*   **Dynamic UI Elements:** Custom button glowing effects, smooth interactive hover transitions (`0.5s`), and sharp typography.
*   **Clean Architecture:** Built from the ground up using semantic HTML5 and clean, organized CSS custom properties (variables) for effortless customization.

---

## 🎨 Color Palette (CSS Variables)

This edition utilizes a specialized neon color profile defined in the `:root`:

```css
:root {
    --main-color: #762abe;        /* Deep Violet */
    --main-color-alt: #8429db;    /* Electric Purple */
    --white-color: white;         /* Contrast Text */
    --black-color: #000000eb;     /* Deep Dark Background */
    --new-color: #f309f4;         /* Neon Fuchsia Accent */
    --trans-time: 0.5s;           /* Smooth Transitions */
    --section-padding: 80px;      /* Consistent Spacing */
}
